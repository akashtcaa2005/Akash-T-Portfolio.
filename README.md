# Akash T. — Portfolio

Personal portfolio of an AI/ML engineer and web security researcher. Dark, terminal-style design built with plain HTML, CSS and JavaScript. No frameworks, no build step.

**Live:** https://akash-t-portfolio.netlify.app/

## Features

- Typewriter hero and animated terminal panel
- Neural-network canvas background
- Experience timeline, projects (BioSense, PredictX, LLM Assistant), skills and certifications
- Responsive layout, respects `prefers-reduced-motion`

## Structure

```
index.html   # content
index.css    # styles and theme variables
index.js     # animations and interactions
```

## Run locally

```bash
git clone https://github.com/akashtcaa2005/Akash-T-Portfolio.git
cd Akash-T-Portfolio
python3 -m http.server 8000
```

Open http://localhost:8000, or just open `index.html` in a browser.

## Customize

Change colours and fonts in the `:root` block at the top of `index.css`. Edit text directly in `index.html`.
