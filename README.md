# Akash T. — AI & Generative AI Engineer Portfolio 🚀

Personal portfolio of **Akash T.**, AI & Generative AI Engineer and final-year B.Tech Artificial Intelligence and Data Science student at Akshaya College of Engineering and Technology, Anna University.

## 🛠️ Tech Stack

- **Frontend & 3D:** React, TypeScript, Three.js, GSAP, WebGL, Tailwind CSS, HTML5, CSS3
- **AI & Generative AI:** LangChain, LangGraph, RAG, Prompt Engineering, FAISS, pgvector, Gemini API, OpenAI API
- **Machine Learning:** Python, Scikit-learn, PyTorch, TensorFlow, XGBoost, Pandas, NumPy, Transformers
- **Backend & DB:** FastAPI, Flask, Node.js, PostgreSQL, Supabase, MySQL
- **Cybersecurity & AI Security:** LLM Safety Evaluation, Prompt Injection Robustness, RAG Security, Threat Modeling

## 🌐 Routes

- `/` — Flagship Home page with interactive 3D scene, rotating roles, and featured sections
- `/about` — About Me, education, learning journey, and AI/security focus
- `/projects` — Filterable project gallery with 6 core projects (PredictX, BioSence, RAG Assistant, ML Applications, Vision Transformer, Customer Purchase Behavior)
- `/experience` — Professional experience timeline (Handshake AI, VEI Technologies, Taras Systems)
- `/skills` — Interactive technical skills dashboard
- `/security` — Dedicated Cybersecurity & AI Security research page
- `/achievements` — Verified academic, competitive, and technical achievements
- `/contact` — Contact details and validated inquiry form
